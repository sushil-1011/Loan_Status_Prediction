# Loan Status Prediction

This project is a **Machine Learning model** that predicts whether a loan application will be **approved or not** based on the applicant’s details.

# Project Description

The goal of this project is to build a predictive model using historical loan application data. The model analyzes various features like applicant income, loan amount, credit history, employment status, etc., and predicts the **Loan Status** (Approved or Not Approved).

##  Technologies Used

- Python  
- Jupyter Notebook / PyCharm  
- Pandas, NumPy, Matplotlib, Seaborn (for data analysis and visualization)  
- Scikit-learn (for building the ML model)

 **Workflow**

1. Data Cleaning and Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature Selection and Encoding  
4. Model Training (e.g., Logistic Regression, Decision Tree, etc.)  
5. Model Evaluation  
6. Making Predictions

**Results** 

The model was successfully trained and tested, providing accurate predictions for loan approval status based on input features.

 **How to Run**

1. Clone the repository  
2. Open the notebook  
3. Run all cells / execute the script  
4. Input sample data to see predictions

# Conclusion
This project demonstrates how machine learning can be used to predict loan approval status effectively. It helps in automating the decision-making process for financial institutions and provides quick and data-driven insights.
